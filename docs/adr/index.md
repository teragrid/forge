# ADR Index

This directory contains Architecture Decision Records (ADRs) for the Forge project.

ADRs document significant architectural and design decisions, their context, and the rationale behind them.

## Format

Each ADR follows the template in [_TEMPLATE.md](_TEMPLATE.md).

## Status legend

| Status | Meaning |
|--------|---------|
| Draft | Under discussion — not yet binding |
| Accepted | Binding decision |
| Deprecated | Superseded by a later ADR |
| Superseded | See the replacement ADR |
