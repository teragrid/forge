forge is a single-binary CLI that bundles the scan-fix-learn loop, LLM gateway, plugin runtime, and ship workflow described in docs/FORGE_FRAMEWORK_SPEC.md.

Usage:
  forge [command]

Examples:
  forge new ts-service my-app              # scaffold a production-grade TypeScript project
  forge scan all                           # check for secrets, vulnerabilities, and code issues
  forge ship                               # run the full 6-stage quality gate before pushing
  forge bugfix --bug "login fails with +"  # diagnose and auto-fix a bug with LLM assistance
  forge config set llm.model gpt-4o        # persist your default LLM model to forge.yml
  forge explain bugfix                     # learn what any command does, inputs, and side-effects
  forge test spec rate-limiter             # generate a 9-point YAML test spec for a feature
  forge test run --spec .forge/specs/rate-limiter/spec.yml  # run tests from the spec

Flags:
      --budget-usd float   per-invocation LLM spend cap in USD (0 = unlimited); sets FORGE_BUDGET_USD
      --dry-run            Preview changes without side effects
      --explain            Print LLM reasoning alongside output
  -h, --help               help for forge
      --json               Emit machine-readable NDJSON output
      --no-color           Disable ANSI color output
      --profile string     Behavior profile (fast|safe|paranoid): adjusts scan strictness, confidence threshold, and LLM token budget
  -q, --quiet              Suppress non-essential output
      --verbose string     Log verbosity level (debug|info|warn)
  -v, --version            version for forge
      --workspace string   Active workspace ID (overrides .forge/workspace)
  -y, --yes                Auto-approve all prompts

Core Workflow:
  bugfix       Diagnose and fix bugs found via reviews, manual tests, or bug reports.
  review       Structured AI review of a diff or file set.
  scan         Scan project across quality families: security, correctness, reliability, and more.
  ship         Deploy a change through the 7-checkpoint pipeline.
  test         Run test families or orchestrate the 4-phase test lifecycle (createΓåÆapproveΓåÆrunΓåÆci).

Build & Generate:
  add          Scaffold a project primitive into an existing project (M3).
  fix          Apply automated fixes for scan/lint findings. --dry-run by default.
  generate     Generate boilerplate: handlers, migrations, models, tests.
  migrate      Manage database schema migrations.
  new          Scaffold a new project from a template or TSD file.
  upgrade      Run a codemod (default: dry-run).

Analysis & Insights:
  audit        Inspect / verify / append to the action ledger.
  eval         Run scenario regression suites (M2.x).
  insights     Show local telemetry rollup from the audit ledger.
  lint         Check project hygiene and conventions.
  metrics      Export token-ledger data as Prometheus text format
  report       Generate a structured project health report
  sla          Maintainer review-SLA dashboard (M3-08).
  spend        Track and enforce LLM API spend limits.

Deploy & Operations:
  backup       Create a point-in-time backup snapshot before risky operations.
  ci           Post-push CI monitor ΓÇö watch, fix, and learn from CI runs (spec ┬º13.6)
  deploy       Deploy the project to the configured adapter (M2).
  incident     Manage incident lifecycle (ADR-021).
  optimize     Analyse and optimise LLM costs, bundle size, and runtime performance (M3).
  postmortem   Lint and verify post-mortem documents (ADR-020).
  rollback     Re-deploy a previous artifact version (M2).
  undo         Reverse the last --apply operation (M3, ADR-024).

AI & Automation:
  agents       Manage background AI agent processes (M2).
  companion    Zero-setup AI pairing: configure every AI tool as a Forge expert.
  learn        Opt-in learning loop for improving scan rules and prompts (M2).
  mcp          Run a Model Context Protocol server for AI chat integration.
  skill        Install the Forge expert role into your project and VS Code Copilot.

Project & Configuration:
  ask          Ask a natural language question about the project via the LLM bridge.
  check        Validate project schema contracts and architectural constraints.
  clean        Find/remove unmanaged scratch files.
  config       Inspect the layered forge configuration.
  context      Manage LLM context files and token budgets.
  docs         Sync and heal project documentation (M2).
  doctor       Check local environment health.
  hygiene      Inspect and manage the .forge/hygiene.yml scratch/managed manifest.
  init         Initialise a directory as a Forge project.
  telemetry    Manage opt-in telemetry spans (ADR-006).

Advanced:
  adopt        Adopt an existing project into the Forge framework.
  eject        Remove Forge framework management from a project (M2).
  explain      Show what a verb does (inputs, outputs, side-effects).
  fixtures     Generate a JSON test fixture file.
  plugin       Inspect and manage Forge plugins (M2.x).
  templates    Browse Forge project templates.
  tsd          Manage Tech Stack Decision (TSD) files.
  version      Print the forge CLI version.

  completion   Generate the autocompletion script for the specified shell
  help         Help about any command


Use "forge [command] --help" for more information about a command.
